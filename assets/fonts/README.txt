Put the Anokha Regular font file here, named exactly one of:

  Anokha-Regular.woff2   (best)
  Anokha-Regular.ttf
  Anokha-Regular.otf

The stylesheet loads it automatically for the large headings (h1, h2). Without it, headings fall back to Arial.

Licence: the copy listed on cufonfonts.com (designer Adopik) is free for personal use only. A business website needs a commercial licence from the designer.

If you convert a .ttf to .woff2, keep the font name unchanged.
